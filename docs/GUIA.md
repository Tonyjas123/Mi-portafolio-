# Guía del Proyecto: Configuración de Entorno

Documentación para la configuración del espacio de trabajo y uso de control de versiones.

## Requisitos y Herramientas

Para ejecutar y colaborar en este proyecto se requieren las siguientes herramientas:

* **Visual Studio Code** como editor de código.
* **Git** instalado localmente.
* Cuenta activa en **GitHub**.

### Pasos de Instalación

1. Clonar el repositorio remoto en tu equipo local.
2. Abrir la carpeta del proyecto en VS Code.
3. Ejecutar el comando en línea `git status` para verificar la rama actual.

## Referencia de Comandos Principales

| Comando | Función Principal | Entorno |
|---------|-------------------|---------|
| `git clone` | Clona el proyecto remoto | Terminal |
| `git status` | Muestra el estado de los archivos | Terminal |
| `git push` | Sube cambios al remoto | Terminal |
